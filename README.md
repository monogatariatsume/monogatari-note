# ものがたり帖

漫画・アニメ・映画を見た日や感想と一緒に記録できる、ブラウザーで動くアプリです。記録と画像は、今使っているブラウザーの中に保存されます。

## 起動方法（Windows）

このアプリはHTMLファイルで動くため、パソコンでは追加のソフトやインストールは必要ありません。

1. エクスプローラーで、このフォルダーを開きます。
2. `index.html` をダブルクリックします。
3. Edge、Chromeなどのブラウザーでアプリが開きます。

ファイルを変更した後は、ブラウザーを再読み込みすると変更が反映されます。終了するときは、ブラウザーのタブを閉じてください。

## スマートフォンだけで使う

スマートフォンから使うには、まずこのフォルダーをHTTPS対応の静的Web公開サービスに一度だけ公開する必要があります。公開サービスのアカウントや設定はこのフォルダーには含まれていません。公開後は、スマートフォンで公開URLを開きます。

- **iPhone:** Safariの共有ボタンを押し、「ホーム画面に追加」を選びます。
- **Android:** Chromeのメニューを開き、「ホーム画面に追加」または「アプリをインストール」を選びます。

一度公開ページを開くと、画面ファイルは端末に保存され、次回以降はホーム画面のアイコンから起動できます。オフライン利用には、公開URLをオンライン中に一度開いて読み込みを完了しておいてください。記録データはスマートフォン内のブラウザーに保存されます。パソコンの記録とは同期されません。

## 使い方

1. 「作品を記録する」からフォームへ移動します。
2. 作品名、ジャンル、見た日を入力します。画像と感想は任意です。
3. 「記録を保存する」を押すと、作品一覧に追加されます。
4. 一覧の「編集」「削除」から記録を変更できます。削除時には確認が表示されます。
5. ジャンルのボタンで絞り込み、右側の選択欄で並べ替えます。

画像は1枚2MBまでです。大きすぎる場合は、画像を小さくするか別の画像を選んでください。

## 保存について

記録はこのブラウザーに保存されます。ブラウザーのデータを消すと記録も消えます。また、記録は保存したブラウザーと端末でのみ見られ、別の端末には同期されません。ブラウザーのデータ削除や閲覧データ消去を行うときはご注意ください。

## ファイル

- `index.html`：画面の内容と入力フォーム
- `style.css`：色、カード、スマートフォン対応などの見た目
- `app.js`：登録、編集、削除、絞り込み、並べ替え、ブラウザー内保存
- `README.md`：起動と使い方の説明
